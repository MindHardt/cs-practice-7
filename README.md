# Практическая работа №7

Форк: https://github.com/marv1n91/cs-practice-7

## Что сделал

- Исправил валидацию URL (было `Any`, нужно было `All`)
- Заменил `StartsWith("https://")` на `Uri.TryCreate` для нормальной проверки URL
- Добавил запрос на перезапись существующего файла
- Реализовал удаление файла при Ctrl+C
- Исправил race condition - добавил `SemaphoreSlim` для синхронизации записи
- Заменил `CopyToAsync` на построчное чтение через `StreamReader`
- Добавил подсчет и вывод количества строк
- Добавил обработку ошибок при скачивании файлов

## Запуск

dotnet run --project App
